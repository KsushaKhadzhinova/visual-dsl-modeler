# Visual DSL Modeler

Web-сервис визуального моделирования структур и процессов на основе собственного языка диаграмм (DSL) с поддержкой UML, BPMN, сетей Петри, ERD. Работает в режиме "diagram as code".

## Технологии
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend/Tools:** Node.js, npm, Git
- **Design:** Figma
